## 02. `git log --projects` — Things I Have Built

### SmartReceipt AI
**Python · FastAPI · OpenCV · Tesseract OCR · SQLite**

An AI-assisted receipt-scanning MVP that extracts structured information from receipt images and validates financial fields.

- Accepts JPEG and PNG receipt uploads with image-size and content checks.
- Uses OpenCV preprocessing and Tesseract OCR to extract receipt text.
- Parses and normalizes common receipt fields, while preserving raw OCR values.
- Checks tax/total/payment consistency and records confidence metadata.
- Flags uncertain or inconsistent results for human review instead of silently guessing.
- Includes automated tests for parsing, normalization, and validation.

**Verification:** 24 automated tests passed in the latest local test run (15 November 2026).

[View source code](https://github.com/gigantic009/SmartReceipt-AI)

### PocketTrack — Personal Expense Tracker
**Node.js · Express · SQLite · HTML · CSS · JavaScript**

A full-stack, multi-user expense tracker for recording income and expenses and understanding monthly cash flow.

- Built account registration and login with bcrypt password hashing.
- Added user-scoped transaction and category data.
- Supports adding, editing, deleting, searching, and filtering transactions.
- Provides monthly income, expenses, savings-rate summaries, category breakdowns, and cash-flow visualization.
- Added input validation, protected API routes, and baseline security middleware.
- Designed a responsive interface for desktop, tablet, and mobile.

**Project status:** Working local application; public deployment is not configured.

[View source code](https://github.com/gigantic009/pockettrack-expense-tracker)
